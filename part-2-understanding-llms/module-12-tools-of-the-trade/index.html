Big Picture

Part II covered the four moving parts of modern LLMs: how they are pretrained at scale, what the 2026 model zoo looks like, how reasoning systems extend test-time compute, how inference is optimized, and how interpretability tools open the black box. This chapter is the corresponding toolbox. You will need three families of tools to actually work in Part II: tokenizer libraries (tiktoken, SentencePiece, Hugging Face tokenizers), data pipelines built around FineWeb and its derivatives, and interpretability harnesses (nnsight, TransformerLens, SAELens).

The frontier model APIs (GPT-4o, Claude Opus, Gemini 2.5, Llama-4, Qwen3, DeepSeek-V4) are listed here for completeness; you actually use them in Part III, which is the API chapter.

Library Shortcut

If you want to start probing a real LLM in 30 seconds:

pip install tiktoken transformers nnsight

tiktoken gives you the same BPE that GPT-4o uses, so you can count tokens before paying for them. transformers loads any of the 2024-2026 open-weights frontier models. nnsight exposes the internal activations as Python objects, which is the lowest-friction way to start doing interpretability.
