Libraries & Frameworks

Section 33.2

Multimodal libraries split into the diffusion frameworks (image and video), the audio libraries (speech and music), and the multimodal-LLM toolkits.

33.2.1 Diffusion frameworks

  • diffusers from Hugging Face: the open-source standard. Unified Pipeline API across SD, SDXL, SD3, FLUX, AudioLDM, MusicGen, and video models.
  • ComfyUI: node-based image-generation UI; the de facto power-user interface for SD-family workflows.
  • Automatic1111 WebUI: older but still widely used SD UI.
  • InvokeAI: production-oriented open SD interface.

33.2.2 Audio libraries

  • openai/whisper: the reference ASR library; faster-whisper for production.
  • audiocraft from Meta: hosts MusicGen, AudioGen, and EnCodec.
  • F5-TTS: open-source SOTA TTS as of 2025.
  • Coqui TTS / XTTS: open TTS with voice cloning.

33.2.3 Multimodal-LLM toolkits

  • LLaVA: open vision-language model.
  • InternVL: another open VLM family.
  • Hugging Face transformers' AutoModelForVision2Seq and AutoModelForVisionText2Text: unified VLM API.
