## Slide 1 — DreamBooth
Title slide introducing DreamBooth as a method for teaching Stable Diffusion new concepts.

## Slide 2 — SD Personalization Method
The slide places DreamBooth in a personalization spectrum. Textual Inversion learns a single token embedding with no weight updates from 3-20 images (weak personalization). LoRA fine-tuning learns rank-decomposed weight updates from 10-50 images but risks catastrophic forgetting of the broader class. DreamBooth uses LoRA-controlled matrices with 3-10 target images plus 100-300 class examples to provide strong personalization while preserving generalization.

## Slide 3 — Task
The task is to generate images of a specific person, dog, or building using a few reference images. Rather than introduce a new token, DreamBooth reuses an unusual trigger word (such as [V] or [T] or any rare token) so that "image of a dog" still means any dog, while "image of [V] dog" means the target dog.

## Slide 4 — Challenges
Two key risks are highlighted. The model must avoid catastrophic forgetting (do not replace all dogs with [T] examples), and it must produce diverse outputs (do not copy poses from the small set of [V] examples). The method assumes the target object is an instance of a broader class with which the model is already familiar.

## Slide 5 — Training data
Training data has two streams. The target stream contains a few images of the specific object paired with the prompt "photo of [V] dog". The class stream contains many images of the broader class paired with the generic prompt "photo of a dog"; class images can be synthetically generated by the base SD model.

## Slide 6 — Fine-Tuning with two losses
DreamBooth combines two losses. The object loss is standard noise-reconstruction on the personal prompt-image pairs ("A [V] dog"). The class-preservation (prior-preservation) loss is noise-reconstruction on the broader class sample with the generic class prompt ("An image of a dog"). Together they preserve the class while installing the new instance.

## Slide 7 — Pseudocode
A pseudocode panel formalizes the training loop: at each step, sample both a target image and a class image, compute both losses, and apply their weighted sum.

## Slide 8 — Fine-Tuning

## Slide 9 — Example
The slide shows generated training data (class images) alongside the few target images used to install a specific subject, illustrating how the prior-preservation set scales independently of the target.

## Slide 10 — With LoRA
The slide visually summarizes DreamBooth-with-LoRA: the same two-loss training is applied to LoRA adapter weights instead of the full UNet, drastically reducing checkpoint size while keeping strong personalization.

## Deck-level takeaway
DreamBooth installs a new subject into Stable Diffusion by fine-tuning on 3-10 target images while preserving the broader class via a prior-preservation loss computed on 100-300 class examples. Pairing a rare trigger token with this dual-loss training avoids catastrophic forgetting and preserves prompt generalization, enabling recontextualization, style transfer, view synthesis, accessorization, and synthetic data generation for the personalized subject.
