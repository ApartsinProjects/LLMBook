Libraries & Frameworks

Section 25.2

RAG libraries split into three layers: embedding generators, retrieval frameworks (the "Python glue" between embeddings, vector DBs, and LLMs), and the higher-level orchestration toolkits.

25.2.1 Embedding generators

  • sentence-transformers: the self-hosted Python library for running open embedding models. Ships hundreds of pretrained models including BGE, E5, and all-MiniLM.
  • FlagEmbedding (BGE): from BAAI; the open SOTA on the MTEB leaderboard for most of 2024-2025.
  • OpenAI embeddings API: text-embedding-3-small and -large.
  • Cohere Embed v3: multilingual; the best off-the-shelf API for non-English retrieval.
  • Voyage AI: Anthropic-affiliated embedding API.

25.2.2 Retrieval frameworks

  • LangChain: the most-used RAG framework. Loaders, splitters, retrievers, chains, agents. The opinionated abstractions occasionally fight you, but the ecosystem is unmatched.
  • LlamaIndex: smaller, more focused on RAG specifically. Better for ingestion-heavy pipelines.
  • Haystack from deepset: pipeline-oriented; the right pick for hybrid search and complex retrieval graphs.
  • Semantic Kernel from Microsoft: .NET-friendly orchestration.

25.2.3 Reranker libraries

  • rerankers from AnswerDotAI: unified API across reranker models.
  • Cohere Rerank: the most-used managed reranker.
  • sentence-transformers cross-encoders: self-hosted reranker option.

25.2.4 Comparing the libraries

Library Layer Best for Tradeoff
sentence-transformers Embedding Self-host any open model You manage GPU
LangChain Framework Tutorials, ecosystem Heavy abstractions
LlamaIndex Framework Ingestion-heavy RAG Smaller ecosystem
Haystack Framework Pipeline-oriented teams Less ChatGPT-style
Cohere Rerank Reranker Quality boost in one line Per-call cost
A working stack

Sentence-transformers BGE or E5 for embedding, Qdrant or pgvector for storage, Cohere Rerank for reranking, LangChain or LlamaIndex for orchestration. Most production RAG systems in 2026 are a variant of this stack.
