Part Overview

The appendices provide reference material organized into three groups. Foundations covers the mathematical and ML prerequisites every transformer relies on. Production Infrastructure covers Docker and the containerization patterns used to ship LLM systems. For Instructors contains course syllabi, reading pathways, intermediate projects, the capstone project, and named production war stories for classroom discussion. Framework, tooling, and ops material that previously lived here has been consolidated into the part-specific Tools of the Trade chapters so it sits next to the content that uses it.

Big Picture

These appendices serve two purposes: they provide prerequisite refreshers you can consult before diving into specific chapters, and they offer practical framework guides you will return to when building real projects. Think of them as the book's toolbox.
