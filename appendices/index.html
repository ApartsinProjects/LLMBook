A Pragmatic Educator

Part Overview

The appendices provide essential reference material organized into four groups. Foundations covers mathematical prerequisites, ML essentials, Python tooling, environment configuration, and version control. Framework Guides offers hands-on introductions to HuggingFace, LangChain, and the broader LLM tooling ecosystem. Infrastructure and MLOps covers GPU hardware, experiment tracking, inference serving, distributed computing, containerization, and cross-cutting reference catalogs. Finally, Pedagogical Kit contains the capstone rubric, intermediate projects, war stories, the problem-solution key, and the 2026 freshness index.

Big Picture

These appendices serve two purposes: they provide prerequisite refreshers you can consult before diving into specific chapters, and they offer practical framework guides you will return to when building real projects. Think of them as the book's toolbox.
