Agent Frameworks

LangGraph, CrewAI, AutoGen, OpenAI Agents SDK, Semantic Kernel, smolagents, PydanticAI: pick a framework, wire a loop, plug in tools.

What this appendix is

A reference for the major agent-orchestration frameworks of 2026. It is paired with Chapter 24 (Agents) and Chapter 25 (Agent Safety), which cover the conceptual foundations: what an agent loop is, why tool use changes the failure-mode profile, when to reach for a multi-agent topology. This appendix is the engineering counterpart: install command, minimal agent loop, tool-plumbing snippet, and a short comparative perspective for each framework.

The market sorted itself between 2024 and 2026 into three loose tiers. Production-grade infrastructure (LangGraph, AutoGen, OpenAI Agents SDK) optimizes for observability, durable state, and team-friendly type contracts. Lightweight Python-native frameworks (smolagents, PydanticAI) optimize for clarity and minimal cognitive overhead. Multi-agent orchestration platforms (CrewAI, Semantic Kernel) optimize for role-based collaboration patterns. Pick by your dominant constraint, not by Twitter momentum.

Library Shortcut
pip install langgraph                # graph-based agent runtime + checkpointing
pip install crewai                   # role-based multi-agent collaboration
pip install pyautogen                # Microsoft's AutoGen multi-agent
pip install openai-agents            # OpenAI's first-party Agents SDK
pip install semantic-kernel          # Microsoft's plugin-oriented framework
pip install smolagents               # Hugging Face's minimalist agent
pip install pydantic-ai              # Pydantic-team type-safe agent

Read Chapter 24 first if you have not built an agent before. Come here after you have a problem in mind and need to pick a framework: each entry opens with a one-line decision rule (e.g., "LangGraph if you need durable state across long-running agents"). The comparison subsection at the end is the fastest way to map your requirements to a choice.
