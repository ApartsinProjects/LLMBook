Production Agent Deployment: Observability, Cost Control, Guardrails

Section F.3
Stub Section

This section will cover the framework-agnostic operational concerns that turn a working agent prototype into a deployable service: structured tracing through LangSmith / Langfuse / OpenTelemetry, token-budget enforcement, retry and timeout policies, max-iteration caps, input/output guardrails and PII redaction, MCP-based tool isolation, A2A protocol bridges between heterogeneous agent stacks, and durable state recovery for long-running workflows. Recipes will be provided for LangGraph, CrewAI, AutoGen, and the OpenAI Agents SDK.

For the framework selection guide, see Section F.1. For the conceptual treatment of production agent architecture, see Chapter 26.5 (Production Agent Architecture) and Chapter 27.4 (Custom Tool Design).
