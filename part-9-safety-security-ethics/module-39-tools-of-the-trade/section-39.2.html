Libraries & Frameworks

Section 39.2

Safety libraries split into guardrails frameworks (which wrap LLM calls with validators), red-team toolkits, and privacy-preserving training libraries.

39.2.1 Guardrails frameworks

  • Guardrails AI: Python framework for input/output validation with a "RAIL spec" DSL.
  • NVIDIA NeMo Guardrails: programmable guardrails using the Colang DSL. Strong on dialog-policy enforcement.
  • LLM Guard: scanner-based guardrails from Protect AI.
  • Aporia Guardrails: commercial alternative with a Python client.

39.2.2 Red-team libraries

  • Garak: probe-based vulnerability scanner across 50+ failure modes.
  • PyRIT: orchestration framework for automated adversarial testing.
  • Garak source (alternative mirror).
  • prompt-injection-defenses: curated reference of injection patterns.

39.2.3 Privacy-preserving training

  • Opacus: differential-privacy library for PyTorch from Meta.
  • TensorFlow Privacy: DP-SGD for TensorFlow.
  • PySyft from OpenMined: federated learning and secure computation.
  • Flower: open federated-learning framework.
