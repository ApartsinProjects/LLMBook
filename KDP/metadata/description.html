Build and Operate Production LLM Systems and Agents from First Principles

A 79-chapter LLM textbook (Chapters 0 through 78), 1,000+ pages, that takes you from PyTorch fundamentals to shipping autonomous agents in production. 15 parts plus 6 reference appendices, for engineers, researchers, and students who need to build and operate real LLM systems. The Sixteenth Edition adds a new chapter on LLM-powered recommender systems (TIGER, LLaRA, P5), a complete audio and speech track (codecs, wav2vec, HuBERT, Whisper, CLAP), a PyTorch reference appendix, and a signal-processing primer for audio.

If you have spent the last year learning LLMs from scattered blog posts and outdated tutorials, this book is for you. Every chapter answers a question someone shipping LLM systems has actually had to answer: how attention works, how to fine-tune on your data, how to build an agent that uses tools without going off the rails, how to evaluate it, and how to run it reliably at scale.

What you will learn

  • Foundations (Ch 0-10): PyTorch, NLP, tokenization, attention and Transformer from scratch, decoding, pretraining and scaling laws, reasoning and test-time compute, inference optimization, interpretability.
  • Training and adapting (Ch 11-19): provider APIs, prompt engineering, synthetic data, fine-tuning, PEFT (LoRA, QLoRA, DoRA), distillation, alignment (RLHF, DPO, RLVR, GRPO).
  • Multimodal and agentic (Ch 20-30): vision-language, audio, video, 3D, omni-models; agent foundations, tool use (function calling, MCP, A2A), multi-agent systems, agent safety.
  • Retrieval and conversation (Ch 31-40): embeddings, vector databases, RAG, advanced and agentic RAG, information extraction, conversational design, voice and realtime multimodal, LLM recsys.
  • Evaluation, security, governance (Ch 42-56): evaluation, LLM-as-judge, prompt injection, guardrails, privacy, bias and fairness, watermarking, EU AI Act.
  • Scale, LLMOps, industries (Ch 57-74): frontier hardware, distributed training, serving, reliability, healthcare, finance, legal, education, cybersecurity, government, manufacturing.
  • Research frontiers (Ch 75-78): state-space models, Mamba, mixture-of-experts, world models, open problems, 2026 retrospective.

What makes it different

  • Eight goal-based reading pathways for RAG engineers, agent builders, ML practitioners, researchers, safety specialists, founders, instructors, and generalists.
  • Course-ready syllabi for undergraduate and graduate engineering / research tracks and professional bootcamps.
  • Built to teach: hundreds of hands-on labs (at least one per chapter), worked derivations, diagrams, production-pattern callouts.
  • Up to date for 2026: reasoning models (o1, o3, DeepSeek-R1, Claude 4), test-time compute, modern PEFT, agentic protocols (MCP, A2A, AG-UI), multimodal foundation models, FlashAttention-3, PagedAttention, RLVR.
  • End-to-end capstone project: design, build, evaluate, and present a production-grade LLM application that integrates every major skill.

Who this book is for

Software engineers, ML practitioners, researchers, domain specialists, and educators. Familiarity with Python is assumed; the Mathematical Foundations appendix covers the prerequisites.
