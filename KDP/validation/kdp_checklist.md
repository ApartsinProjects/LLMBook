# KDP Pre-Submission Checklist

Use this checklist immediately before clicking "Publish" on the KDP web form.

## Files

- [ ] `KDP/output/building-conversational-ai-llms-agents.epub` exists
- [ ] EPUB file size is **under 650 MB** (KDP upload limit). Current: **70.76 MB** ✓
- [ ] Cover file `KDP/cover/cover_kdp.jpg` exists
- [ ] Cover dimensions are **1600 × 2560** (KDP recommended)
- [ ] Cover is sRGB JPEG (not CMYK, not PNG, not progressive JPEG)
- [ ] Cover file size is under 50 MB. Current: **418 KB** ✓

## Validation

- [ ] `python KDP/validation/structural_check.py` exits **0** with no errors
- [ ] (Recommended) `epubcheck output.epub` exits 0; if not, errors are reviewed and acceptable. See `epubcheck_instructions.md`.
- [ ] Kindle Previewer opens the EPUB without errors
- [ ] Kindle Previewer's Table of Contents navigates correctly
- [ ] Kindle Previewer's Cover displays the right image
- [ ] At least 5 randomly-sampled chapters render correctly in Kindle Previewer
- [ ] Code blocks wrap reasonably (no horizontal-scroll-required content)
- [ ] Images load (not broken-image icons)
- [ ] Internal links jump to the right chapters

## Metadata

- [ ] Title and subtitle are correct in `KDP/metadata/metadata.yaml`
- [ ] Both authors listed in correct order
- [ ] Description (`KDP/metadata/description.html`) is **under 4000 characters**. Current: **3,359** ✓
- [ ] Description renders correctly when rendered as HTML (preview in browser)
- [ ] Keywords list (`KDP/metadata/keywords.txt`) has **exactly 7 entries**
- [ ] Each keyword is **under ~50 characters** and contains no special characters
- [ ] Three BISAC categories chosen (`KDP/metadata/categories.txt`)
- [ ] Categories exist on KDP's current category browser (verify on the form)

## Account

- [ ] Tax interview completed (W-8BEN for non-US, W-9 for US)
- [ ] Bank account on file for royalty payments
- [ ] (Optional) Author Central profile created at https://authorcentral.amazon.com

## Decisions made

- [ ] Royalty plan chosen: **35% recommended** (file is 70 MB; 70% plan loses USD 10.61/sale to delivery fees)
- [ ] List price set: USD ___________ (recommended USD 14.99 - 19.99)
- [ ] DRM: **disabled** (recommended for technical books)
- [ ] KDP Select: **disabled** initially (can enroll later; locks Amazon exclusivity for 90 days)
- [ ] Territories: **worldwide**
- [ ] Lending: enabled (recommended)

## Legal

- [ ] You have the rights to all content (text, code samples, illustrations)
- [ ] All third-party images and figures are either:
  - Original work by the authors
  - Licensed for commercial use (CC-BY-SA, public domain, with attribution)
  - Generated by you or an AI tool whose output license permits commercial use
- [ ] Bibliographic citations follow consistent attribution standard
- [ ] Code samples are either original or under a permissive license (MIT/Apache); upstream attributions noted

## Final review

- [ ] You've read the entire `KDP/PUBLISHING_GUIDE.md`
- [ ] You've previewed the EPUB on at least one Kindle device (Kindle app on phone counts)
- [ ] You're prepared for the 24-72 hour Amazon review window
- [ ] You have a launch promotion plan (social media, mailing list, colleagues)
