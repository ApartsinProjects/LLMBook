Plain-HTML Math Examples for Kindle

Six sections demonstrating how to render mathematics with nothing but <i>, <sub>, <sup>, <span>, and CSS. Survives every KDP conversion. Reflows with body text. Scales with font size. Matches body weight.

1. Inline math in prose

The output of a model for the i-th example is written yi, and its prediction is ŷi. The training set consists of n examples, indexed by i = 1, 2, …, n. Each example contributes a residual ŷi − yi which we square before averaging.

For a binary classifier we model the probability of the positive class as P(y = 1 | x) = σ(z), where σ is the sigmoid and z is the pre-activation wTx + b. Multi-class generalizes via softmax: the probability of class k is proportional to ezk, normalized by Σj ezj.

Gradient descent updates parameters by θt+1 = θt − η ∇ L(θt), where η is the learning rate and ∇ L is the gradient of the loss with respect to θ.

Two events A and B are independent when P(A ∈ B) = P(A)⋅P(B). The conditional probability of A given B is P(A | B) = P(A ∈ B)P(B).

4. Formula gallery

Twelve common formulas, each rendered as a display block. Every formula uses only plain HTML and the CSS in html_math.py.

Sigmoid
σ(x) = 11 + e−x

Squashes any real number into the open interval (0, 1).

Softmax (k-th output)
σ(z)k = ezkKΣj=1 ezj

Generalizes sigmoid to K classes. Each output lies in (0, 1) and the K outputs sum to 1.

Tanh
tanh(x) = ex − e−xex + e−x

Squashes to (−1, 1). Zero-centered, unlike sigmoid.

ReLU
ReLU(x) = max(0, x)

Identity for positive inputs, zero otherwise. The workhorse activation of modern deep nets.

Cross-entropy loss
L = −1n nΣi=1 KΣk=1 yik log ŷik

Multi-class classification objective. The negative log-likelihood of the correct class.

Adam update
θt+1 = θt − η mt√vt + ε

Adaptive learning rate per parameter, using running estimates of the first and second moments of the gradient.

Layer normalization
xi = xi − μ√σ2 + ε

Normalizes each input across feature dimensions to zero mean and unit variance, then applies a learned affine.

Scaled dot-product attention
Attention(Q, K, V) = softmax(QKT√dk) V

Transformer attention. Scaling by √dₖ keeps the softmax in a useful range as dimensionality grows.

KL divergence
KL(P || Q) = Σx P(x) log P(x)Q(x)

Asymmetric measure of how much distribution Q diverges from a reference P. Never negative; zero iff P = Q.

Bayes' theorem
P(A | B) = P(B | A) P(A)P(B)

Posterior is proportional to likelihood times prior.

Gaussian density
p(x) = 1√2π σ e−(x − μ)22σ2

Univariate normal distribution with mean μ and standard deviation σ.

Expectation of a function of X
E[f(X)] = ∞∫−∞ f(x) p(x) dx

Linear operator. For a discrete X, replace the integral with a sum.

6. Typography edge cases worth checking

Stacked sub-subscripts. Position xi1 inside example i runs against the 1st coordinate. The inner subscript uses italic for the variable but normal weight for the digit.

Hat over a fraction. The estimator 1n Σi xi puts the hat above the entire fraction, not just the numerator. The .hat class wraps the whole .frac span.

Multi-character operators. Names like MSE, KL, sin, and log render upright to distinguish them from a product of italic variables (compare MSE which reads as a product).

Bracket grouping. Use literal parentheses for grouping; they reflow correctly. (a + b)2 = a2 + 2ab + b2.

Vector and overarrow. The displacement vector v⃗ has magnitude |v⃗| and points in the direction of n.

Sample mean with bar. The sample mean x̄ = 1n nΣi=1 xi is an unbiased estimator of μ.

Square root with nested radicand. The golden ratio is φ = 1 + √52, and its conjugate is φ−1 = √5 − 12.
