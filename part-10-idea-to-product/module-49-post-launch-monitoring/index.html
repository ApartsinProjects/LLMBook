Post-Launch Monitoring & Iteration

Eval-in-prod, drift detection, retraining cadence.

Big Picture

Shipping is not the finish line for an AI product, it's the start of the second loop. This chapter covers post-launch monitoring and iteration: eval-in-prod, drift detection, and the retraining cadence that keeps a model honest as the world it answers questions about keeps moving.

The 2024-2025 observability stacks that emerged as the de-facto production toolchain are Langfuse, LangSmith, and Arize Phoenix: each gives you trace-level visibility, eval pipelines, and dataset versioning out of the box. The canonical silent-drift case is Anthropic's Claude 3.5 Sonnet "new" release (Oct 2024), which kept the same API model identifier while shifting underlying behavior, breaking apps that had implicit prompt-and-output assumptions baked in. Apps without monitoring discovered the change from user complaints; apps with eval-in-prod saw the regression on their dashboard the same day.
