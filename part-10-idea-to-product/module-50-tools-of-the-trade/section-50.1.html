Platforms

Section 50.1

50.1.1 AI-native code editors and assistants

  • Cursor: VS Code fork with first-class LLM integration; the de facto AI editor.
  • Claude Code: Anthropic's terminal-based agentic coding tool.
  • GitHub Copilot: the original AI coding assistant; now multi-model.
  • Cline: open-source VS Code agent.
  • Aider: terminal-based pair programmer.
  • Windsurf: Codeium's AI-first IDE.

50.1.2 Project and document tooling

  • Linear: issue tracker / project management with strong AI integrations.
  • Notion: docs + databases with native AI.
  • Height: AI-native project tool.
  • Jira for enterprise.

50.1.3 Design tooling

  • Figma with the First Draft AI plugin and other generators.
  • Galileo AI: text-to-UI generation.
  • Uizard: AI-first UI design.
  • v0 by Vercel: text-to-React-component.

50.1.4 Analytics

  • Mixpanel.
  • PostHog: open-source, self-hostable.
  • Amplitude.
  • Statsig: feature flags + analytics.
