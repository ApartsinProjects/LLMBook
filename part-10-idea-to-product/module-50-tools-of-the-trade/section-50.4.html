Models

Section 50.4

Part X is mostly model-agnostic. The product-side recommendation is to pick a model that fits your budget and quality bar from Chapter 16's tier table, and to standardize on it across the team to keep eval results comparable.

50.4.1 Models behind product tools

  • Cursor: defaults to Claude / GPT family with user-selectable model per request.
  • Claude Code: Claude Sonnet / Opus.
  • GitHub Copilot: multi-model (GPT-4o, Claude Sonnet, Gemini, o1 / o3 series).
  • OpenAI Codex (cloud): GPT-5 / o3-codex behind the cloud editor.

50.4.2 Model picks for embedded AI features

For embedded features (a "summarize this" button, an in-app chatbot), pick from Chapter 16's tiers. The workhorse tier (GPT-4o, Claude Sonnet, Gemini Flash) is the right default for almost all in-product AI features. Drop to mini/Flash tiers when latency matters; escalate to Opus / GPT-5 only for genuinely hard reasoning tasks.
