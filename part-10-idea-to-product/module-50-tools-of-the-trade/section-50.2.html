Libraries & Frameworks

Section 50.2

Part X's libraries focus on the application-development side: web frameworks, deployment, CI, and the AI-coding-tool integrations.

50.2.1 Web frameworks for AI apps

  • Next.js + Vercel AI SDK: the dominant React stack for AI products.
  • FastAPI: Python backend default.
  • Streamlit and Gradio: rapid demo UIs.
  • Chainlit: chat-app-specific framework.

50.2.2 Deployment

  • Vercel: Next.js hosting.
  • Cloudflare Workers AI: edge inference.
  • Fly.io, Render, Railway: PaaS for AI apps.
  • Modal: serverless Python with GPUs.

50.2.3 AI coding tool CLIs

  • Claude Code CLI.
  • Aider CLI.
  • OpenAI Codex CLI.
  • GitHub Copilot CLI.
