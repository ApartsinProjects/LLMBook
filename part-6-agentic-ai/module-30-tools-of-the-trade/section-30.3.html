Datasets & Benchmarks

Section 30.3

Agent benchmarks have to test something that traditional NLP benchmarks do not: whether the system can complete an actual multi-step task with side effects. The benchmarks below are the ones with active leaderboards as of 2026.

30.3.1 Software engineering agent benchmarks

  • SWE-bench and SWE-bench Verified: GitHub issues resolved end-to-end. The most-cited coding-agent benchmark.
  • SWE-Lancer: freelance-style coding tasks with monetary value.
  • AgentBench: broad agent evaluation across 8 distinct environments.

30.3.2 Browser and web agent benchmarks

  • WebArena: web-based tasks in containerized environments (shopping, GitLab, social).
  • VisualWebArena: multimodal extension.
  • BrowseComp: OpenAI's web-research benchmark.
  • MMInA: multi-hop information-seeking on real websites.

30.3.3 Tool-use and general agent benchmarks

  • Berkeley Function-Calling Leaderboard (BFCL): still the standard tool-use benchmark.
  • tau-bench: customer-service agent benchmark from Sierra.
  • GAIA: general AI assistants benchmark.

30.3.4 Comparing the benchmarks

30.3.1 Agent benchmarks (2026)
Benchmark Domain SOTA pass rate Caveat
SWE-bench Verified Real GitHub issues ~60-75% (frontier) Verified subset
WebArena Web tasks ~50% Containerized envs only
GAIA General assistance ~70% (frontier) Test set partially private
BFCL Function calling ~90% (frontier) Synthetic functions
tau-bench Customer service ~50-70% Two domains only
Beware single-number rankings

Agent benchmarks aggregate many sub-tasks. A high single-number score can hide catastrophic failure on a critical sub-domain. Always look at the breakdown.
