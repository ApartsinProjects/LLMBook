## Recommended remediation

If the team wants STRICT enforcement of the canonical Who/Situation/Result/Lesson template:

1. **Title pass:** Rename every callout-title to `Real-World Scenario: <Short descriptive title>`. Currently most use only the descriptive title without the `Real-World Scenario:` prefix.
2. **Field-label canonicalization** (mechanical replace per non-canonical label observed above):
   - `Background:` / `Context:` / `Setup:` / `Scenario:` / `Problem:` / `Challenge:` -> merge into `Situation:`
   - `Approach:` / `Action:` / `Decision:` / `How:` / `Solution:` / `Method:` / `Process:` -> merge into `Situation:` (or drop, since the template treats the action as part of Situation)
   - `Outcome:` / `Impact:` / `Numbers:` / `Effect:` -> rename to `Result:`
   - `Takeaway:` / `Lessons:` / `Conclusion:` / `Recommendation:` / `Insight:` -> rename to `Lesson:`
3. **Compress to four paragraphs:** Many callouts have six to eight sub-fields. The strict template forces merging intermediate steps into `Situation:`.
4. **Nested-bold pass:** Ensure every Lesson paragraph uses `<p><strong>Lesson:</strong> <strong>...</strong></p>` so the one-line takeaway is visually distinct.
5. **Alternative recommendation:** ADOPT the de-facto extended template as canonical (Who / Situation / Problem / Dilemma / Decision / How / Result / Lesson), since the reference example in `section-0.1.html` ITSELF uses the extended form. Forcing the strict 4-field template would regress the richest callouts. Decide which template wins before any mass rewrite.
