Platforms

Section 36.1

Part VIII's platforms split into evaluation services (which run the eval suites) and serving / observability services (which run the production traffic).

36.1.1 Evaluation platforms

  • OpenAI Evals: open-source eval framework with a registry of community-contributed evals.
  • Stanford HELM: holistic eval platform with public leaderboards.
  • Inspect AI: UK AI Safety Institute's framework; strong on safety and agentic evals.
  • LangSmith: managed eval and tracing for LangChain apps; also works standalone.
  • Braintrust: eval-first observability platform; popular with prompt-engineering teams.

36.1.2 Serving platforms

  • vLLM: open-source LLM serving with PagedAttention.
  • Text Generation Inference (TGI): Hugging Face's production server.
  • SGLang: newer high-throughput server.
  • NVIDIA Triton: framework-agnostic inference server.
  • TensorRT-LLM: NVIDIA's optimized inference runtime.

36.1.3 Observability platforms

  • Arize: ML and LLM observability with strong drift detection.
  • Phoenix: Arize's open-source companion for local tracing.
  • Helicone: proxy-based cost and latency observability.
  • Langfuse: open-source competitor to LangSmith.
  • Traceloop: OpenTelemetry-native LLM tracing.
