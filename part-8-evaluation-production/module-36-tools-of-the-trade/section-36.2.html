Libraries & Frameworks

Section 36.2

The eval and production Python libraries split into eval harnesses, serving libraries, and observability SDKs.

36.2.1 Eval harnesses

  • lm-evaluation-harness: EleutherAI's harness. The most-cited eval library for academic benchmarks (MMLU, HellaSwag, ARC, GSM8K, etc.).
  • Inspect AI: UK AISI; Python-native, supports agent and tool-use evals out of the box.
  • openai/evals: open-source eval framework.
  • simple-evals: OpenAI's simpler library used for their public model cards.
  • RAGAS: RAG-specific eval framework with LLM-as-judge metrics.
  • deepeval: pytest-style LLM eval framework.

36.2.2 Serving libraries

  • vLLM: PagedAttention + continuous batching.
  • TGI: HuggingFace production server with Apache 2.0 core.
  • SGLang: structured generation + RadixAttention.
  • Triton Inference Server: NVIDIA's general-purpose inference server.
  • LoRAX: multi-LoRA serving (one base, many adapters).

36.2.3 Observability SDKs

  • LangSmith SDK.
  • Langfuse SDK.
  • Phoenix (Arize OpenSource): OpenTelemetry-based tracing.
  • Helicone.
  • OpenTelemetry + OpenLLMetry: vendor-neutral instrumentation.
