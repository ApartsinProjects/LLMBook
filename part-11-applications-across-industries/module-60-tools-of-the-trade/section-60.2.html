Libraries & Frameworks

Section 60.2

Each industry has its own connector / SDK ecosystem. The libraries below are the most commonly used integration points for building LLM applications in each vertical.

60.2.1 Healthcare libraries

  • FHIR standard + smart-on-fhir client: standard EHR data access.
  • spaCy 3.7+ with transformers: the umbrella NLP library that modernized in 2024-25; scispaCy is the medical subset.
  • scispaCy: biomedical NLP.
  • MedSpaCy and BioMedICUS: additional medical NLP libraries; useful when scispaCy gaps appear.
  • BiomedBERT family.
  • PyHealth, FHIR.resources, fhirpy: Python FHIR libraries for production EHR integration.

60.2.2 Finance libraries

  • SEC EDGAR + sec-edgar-api: filings ingestion.
  • FinBERT: financial sentiment.
  • FinGPT: open finance LLM.
  • openbb: open-source investment research platform.
  • yfinance: Yahoo Finance data (still useful for prototypes).
  • polygon and databento: production-grade market data APIs.

60.2.3 Legal libraries

  • CourtListener + courtlistener API: case-law access.
  • Legal-BERT.

60.2.4 Education libraries

  • LTI standard for LMS integration.
  • Common Cartridge / IMS Global standards: the broader interoperability layer for educational content.
  • Canvas LMS API.

A 2024-25 trend in vertical AI worth flagging: open-source domain-specific LLMs (OpenMed, BioMedLM, MedFound for medicine; FinGPT for finance) are useful but rarely beat the frontier general models on the same vertical tasks. The standard recipe in 2026 is continued pretraining on a domain corpus plus a normal general post-training, not from-scratch domain models.
