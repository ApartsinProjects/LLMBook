LLMs in Cybersecurity

SOC automation, code review, threat intel, defense and offense. What 2026 settled about LLMs in blue-team and red-team work.

Big Picture

Cybersecurity is the only LLM application area where attackers and defenders are both adopting the technology at scale simultaneously. The defender side wins at scale because of mature SIEM/SOAR infrastructure to plug into. The attacker side wins at velocity because there is no compliance team slowing them down. The 2026 cybersecurity LLM playbook is fundamentally about whether you can deploy LLM automation faster than your adversaries can. Section 76.1 covers the blue-team use cases. Section 76.2 covers the red-team uses that defenders must understand. Section 76.3 covers the LLM-specific attack surface (OWASP Top 10, MITRE ATLAS). Section 76.4 covers the trust-boundary architecture. Section 76.5 closes with the vendor landscape, and Section 76.6 is the longer production-pattern companion.

Sections in This Chapter

  • 76.1 Defensive (Blue Team) LLM Use Cases SOC alert triage, phishing analysis, code review for vulnerabilities, postmortems, and detection-as-code generation.
  • 76.2 Offensive (Red Team) Use Cases Phishing content generation, vulnerability research acceleration, malware adaptation, and what defenders need to understand.
  • 76.3 LLM-Specific Attack Surface OWASP Top 10, MITRE ATLAS, prompt injection, training-data poisoning, membership inference, model extraction.
  • 76.4 Trust Boundaries for LLM Systems Input classification, output filtering, tool-call sandboxing, authorization, and the SOC-workflow auto-act safety table.
  • 76.5 Cybersecurity LLM Vendors and Further Reading Security Copilot, Charlotte AI, Tines, Wiz, OWASP, MITRE ATLAS, NIST.
