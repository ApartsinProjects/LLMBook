Voice and Realtime Multimodal Assistants

Big Picture

Text chat is one mode; conversational AI also lives in voice, video, and screen-sharing assistants. This chapter covers voice agents (ASR, TTS, turn-taking), streaming audio architectures, the realtime API surface from major vendors (Gemini Live, GPT-4o Realtime, Anthropic), audio token budgets, and the open-source realtime stack (Moshi, Pipecat, LiveKit). It merges material from the Conv AI Voice section and the Streaming/Realtime Multimodal chapter into one focused home.

Sections in This Chapter

  • 40.1 Voice Agents and Speech Interfaces Voice agents combine the naturalness of speech with the power of agentic tool use.
  • 40.2 Streaming Audio Architectures A streaming audio conversation with a model is an unforgiving real-time system.
  • 40.3 Gemini Live and GPT-4o Realtime API Both GPT-4o Realtime and Gemini Live expose a WebSocket-based, event-driven protocol for streaming audio and tool calls.
  • 40.4 Audio Token Budget and Latency Engineering Latency in a streaming audio system is determined by the token rate of the audio codec, the time-to-first-audio-token (TTFAT) of the model, and the cumulative network and buffer overhead.
  • 40.5 Open-Source Realtime: Moshi, Pipecat, LiveKit Agents The open-source realtime stack in 2026 has three layers.
