Datasets & Benchmarks

Section 71.3

Part X's measurement story is developer-productivity benchmarks (SWE-bench, SWE-Lancer), event analytics, and revenue funnels rather than traditional ML datasets.

66.3.1 Developer-productivity benchmarks

  • SWE-bench (Princeton, 2023) is the real-GitHub-issue benchmark that every AI coding tool now reports against, with Verified being the 500-issue cleaned subset. Its objective is to measure whether an AI tool can resolve actual production issues end-to-end, which matters because LeetCode-style tests do not capture multi-file editing. Pick SWE-bench Verified scores for cross-tool comparison of AI coding products in 2026.
  • SWE-Lancer (OpenAI, 2025) is the monetary-value coding benchmark built from real Upwork freelance jobs, with each task carrying a dollar amount. Its objective is to translate AI coding capability into economic value, which matters when you want to know if buying an AI coding subscription replaces a junior developer. Pick SWE-Lancer for ROI-framed analysis; the dollar values make procurement conversations more concrete.
  • HumanEval (OpenAI, 2021) is the 164-problem function-completion baseline. Its objective is to provide a fast smoke-test benchmark for code generation, which matters as a quick smoke test, although the benchmark has saturated. Pick HumanEval for fast iteration during model selection; for serious comparison, SWE-bench is more diagnostic.
  • CodeContests (Google DeepMind, 2022) is the competitive-programming benchmark built from Codeforces problems, designed to test algorithmic reasoning. Its objective is to evaluate hard algorithmic problem solving where simple completion patterns fail, which matters when you specifically need algorithmic capability rather than glue code. Pick CodeContests for testing competitive-programming-style reasoning; for production code, SWE-bench is more relevant.
